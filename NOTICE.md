# Aviso de créditos — Larinha Teleporter (repositório locwarp-simples)

> LocWarp — https://github.com/keezxc1223/locwarp

As partes reaproveitadas foram as ideias de arquitetura e as chamadas públicas da
pymobiledevice3 usadas no backend original (conexão USB via usbmuxd, túnel RSD para
iOS 17+, e simulação de localização via DVT). O código deste fork foi reescrito em
versão mínima e traduzido para português.
